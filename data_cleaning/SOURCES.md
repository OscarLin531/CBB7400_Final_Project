# Official data sources

Each cycle has its own codebook. The download manifest records the source XPT
URL and SHA-256; the pipeline verifies those hashes before processing.

## Decisions requiring source documentation

- [FPG instrument bridge and direction](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2015/DataFiles/GLU_I.htm).
- [2017-2018 FPG eligibility, zero weights, and published instrument adjustments](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/GLU_J.htm).
- [NHANES weighting tutorial](https://wwwn.cdc.gov/nchs/nhanes/tutorials/weighting.aspx).
- [NHANES variance estimation tutorial](https://wwwn.cdc.gov/nchs/nhanes/tutorials/varianceestimation.aspx).
